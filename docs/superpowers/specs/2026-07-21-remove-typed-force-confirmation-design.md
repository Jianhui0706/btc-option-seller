# 移除强平文字确认设计

## 目标

移除“全账户强制平仓”弹窗中必须输入 `YES` 的交互。用户阅读风险说明后，可直接点击“确认强平”执行，或点击“取消”退出。

## 修改范围

- 删除 `forceConfirm` 输入框及其样式。
- `openForceDialog()` 只负责打开弹窗，不再清空或聚焦输入框。
- `confirmForceClose()` 不再校验 `YES`，点击后直接调用现有 `/control/force_close` 接口。
- 保留风险说明、确认按钮、取消按钮、Escape 关闭行为和请求失败提示。
- 保留远程访问口令输入；它是身份验证，不属于操作确认。
- 保留暂停交易、平掉子组、解除强平锁定、testnet 模拟信号等普通点击确认。

## 验证

- 静态测试确认前端源码不再包含 `forceConfirm`、`输入 YES` 或相关校验提示。
- Vite 生产构建必须成功。
- 浏览器中打开强平弹窗，确认没有文字输入框，取消和确认按钮仍存在。
- 不实际点击“确认强平”，避免触发真实 testnet 账户级清仓。
