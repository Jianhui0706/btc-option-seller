# 策略总览移至四栏导航上方——设计规范

## 目标

调整页面信息层级，使共享的策略总览明确属于整个系统，而不是任何单独栏目。

最终顺序固定为：

1. 系统品牌与运行状态栏
2. “BTC 期权卖方策略仪表板”总览卡
3. 五项共享核心指标
4. 四栏页面切换：仓位、活跃信号、信号日志、仓位日志
5. 当前栏目的专属内容

## 交互与布局

- 总览卡和五项指标随页面正常滚动，不长期占用视口。
- 四栏导航使用独立吸顶容器；滚动越过总览区域后仍可随时切换栏目。
- 刷新数据、暂停/启用开仓和全账户强平仍与四栏导航位于同一操作区。
- 在 701–1120px 宽度使用移动操作菜单，保证安全操作入口始终可达。
- 手机端保持四栏等宽排列，页面不得产生横向溢出。

## 不变范围

- 不修改 TradingView 信号接收、识别、接受或拒绝逻辑。
- 不修改核心指标的计算口径。
- 不修改交易开关、强平确认、策略执行或风控逻辑。
- 不修改后端 API、数据库或 Pine 脚本。

## 验收标准

- 四个路由中的共享总览均显示在四栏导航上方。
- 页面首屏层级清晰：系统总览先于栏目选择。
- 滚动后四栏导航保持可见，且不会遮挡栏目内容。
- 桌面、900px 平板和 390px 手机宽度无横向溢出。
- 平板和手机仍能打开策略操作菜单。
- 前后端现有测试、生产构建及云端路由检查全部通过。
